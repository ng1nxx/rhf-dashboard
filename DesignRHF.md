# Design System Website RHF Catering

Dokumen ini digunakan sebagai acuan desain untuk membuat website resmi **RHF Catering**. Website harus terasa **hangat, bersih, profesional, homey, dan terpercaya**, dengan tetap mempertahankan identitas utama dari logo RHF yang bernuansa orange.

---

## 1. Brand Foundation

### Nama Brand
**RHF Catering**

### Filosofi Nama
RHF diambil dari nama anak pemilik: **Rafi, Hafizh, dan Fatih**. Brand ini lahir dari usaha keluarga yang dirintis dari awal, dimulai dari jualan menggunakan gerobak sederhana, lalu berkembang hingga menerima pesanan dari berbagai client, termasuk dinas/instansi.

### Nilai Utama Brand
- **Mengutamakan rasa** sebagai kualitas utama.
- **Amanah dan terpercaya** dalam melayani pesanan.
- **Rapi dan profesional** untuk kebutuhan acara keluarga, kantor, sekolah, maupun dinas.
- **Hangat dan kekeluargaan** karena brand lahir dari cerita keluarga.
- **Bersih dan praktis** untuk kebutuhan snack box, nasi box, prasmanan, dan makan siang.

### Brand Personality
RHF Catering harus tampil sebagai brand yang:

- Ramah
- Hangat
- Bersih
- Modern
- Profesional
- Sederhana tapi meyakinkan
- Tidak terlalu ramai
- Tidak terlihat seperti desain template murahan

### Brand Message
> Dari usaha keluarga yang dirintis sederhana, RHF Catering tumbuh menjadi layanan catering yang dipercaya karena rasa, kerapian, dan pelayanan.

### Tagline Utama
**Mengutamakan Rasa**

### Layanan Utama
- Snack Box
- Nasi Box
- Menu Prasmanan
- Makan Siang Acara / Instansi
- Konsumsi Rapat
- Acara Keluarga
- Acara Sekolah
- Kegiatan Dinas

---

## 2. Visual Direction

### Arah Visual
Website RHF Catering harus menggunakan pendekatan visual:

**Warm Minimalist Catering Website**

Artinya website dibuat sederhana, bersih, mudah dibaca, tetapi tetap terasa hangat dan menggugah selera.

### Kesan yang Harus Muncul
- Makanan terasa enak dan terpercaya.
- Usaha terlihat profesional, bukan usaha asal-asalan.
- Brand tetap terasa dekat dengan keluarga dan masyarakat.
- Website cocok untuk calon pelanggan umum maupun instansi/dinas.

### Hal yang Harus Dihindari
- Terlalu banyak ornamen.
- Terlalu banyak warna dalam satu halaman.
- Font dekoratif berlebihan.
- Efek 3D/glossy yang terlalu kuat.
- Background terlalu ramai.
- Banyak emoji.
- Layout terlalu penuh.
- Desain yang terlihat seperti hasil generate AI mentah.

## 5. Typography

### Font Direction
Gunakan font sans-serif modern yang bersih dan mudah dibaca.

### Recommended Fonts

#### Heading Font
Pilihan utama:
- `Poppins`
- `Montserrat`

Usage:
- Hero title
- Section title
- Menu package title
- CTA heading
- Logo lockup text bila dibutuhkan

#### Body Font
Pilihan utama:
- `Inter`
- `Nunito Sans`
- `Lato`

Usage:
- Paragraph
- Menu description
- Button text
- Navigation
- Detail layanan

### Font Pairing Rekomendasi

Gunakan salah satu kombinasi berikut:

1. **Poppins + Inter**
   - Kesan: modern, clean, profesional.

2. **Montserrat + Nunito Sans**
   - Kesan: ramah, bold, cocok untuk catering.

3. **Poppins + Lato**
   - Kesan: simple, rapi, mudah dibaca.

### Typography Scale

```css
--text-xs: 12px;
--text-sm: 14px;
--text-base: 16px;
--text-lg: 18px;
--text-xl: 20px;
--text-2xl: 24px;
--text-3xl: 32px;
--text-4xl: 40px;
--text-5xl: 56px;
```

### Heading Rules

#### H1
- Size desktop: `48px - 56px`
- Size mobile: `36px - 42px`
- Weight: `700 - 800`
- Line height: `1.1`

#### H2
- Size desktop: `32px - 40px`
- Size mobile: `28px - 32px`
- Weight: `700`
- Line height: `1.2`

#### H3
- Size: `22px - 28px`
- Weight: `600 - 700`

#### Body
- Size: `16px - 18px`
- Weight: `400`
- Line height: `1.6 - 1.8`

### Text Style Rules
- Jangan gunakan terlalu banyak variasi ukuran font.
- Jangan gunakan font dekoratif untuk body text.
- Gunakan letter spacing kecil untuk label uppercase.
- Pastikan kontras teks kuat dan mudah dibaca.

## 6. Logo Usage

### Logo Utama
Logo utama berupa lingkaran orange dengan icon api/lotus, tulisan RHF, dan teks kecil `Catering`.

### Makna Logo
- **Api**: proses memasak, masakan hangat, semangat usaha.
- **Lotus/Kelopak**: pertumbuhan, keluarga, rasa yang berkembang.
- **RHF**: identitas dari nama anak pemilik.
- **Orange**: kehangatan, makanan, energi, dan rasa.

### Logo Placement
Gunakan logo di:
- Navbar kiri.
- Footer.
- Hero section bila dibutuhkan.
- Card kecil sebagai brand marker.
- WhatsApp share image.

### Logo Size
- Navbar desktop: tinggi `48px - 56px`.
- Navbar mobile: tinggi `40px - 48px`.
- Footer: tinggi `64px - 80px`.
- Hero badge: maksimal `120px`.

### Clear Space
Jarak aman minimal di sekitar logo adalah setara dengan tinggi huruf `R` pada logo.

### Jangan Dilakukan
- Jangan masukkan nomor HP ke dalam logo.
- Jangan menambahkan banyak teks di dalam logo.
- Jangan menaruh logo di background yang terlalu ramai.
- Jangan membuat logo gepeng atau tidak proporsional.
- Jangan memberi efek bayangan berlebihan.

- Jangan gunakan teks orange di atas background orange.
- Button harus jelas terlihat.
- Semua gambar makanan harus punya alt text.
- Form input harus punya label.
- Navigasi bisa diakses dengan keyboard.
- Ukuran body text minimal `16px`.
- Jangan hanya mengandalkan warna untuk membedakan status.

### Alt Text Example
- `Snack box RHF Catering untuk acara rapat`
- `Paket nasi box RHF Catering dengan lauk dan sayur`
- `Menu prasmanan RHF Catering untuk acara keluarga`
